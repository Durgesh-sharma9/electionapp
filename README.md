# महापुरा चुनाव संपर्क एवं मतदाता पोर्टल (Mahapura Election Outreach Portal)

React + Node.js (Express) + MongoDB Atlas पर आधारित विशेष चुनावी जनसंपर्क एवं मतदाता प्रबंधन सिस्टम।

## मुख्य विशेषताएँ (Key Features)

1. **सिंगल एवं बल्क डेटा एंट्री (Single & Bulk Import):**
   - **नया संपर्क:** नाम, 10-अंकों का मोबाइल नंबर, वार्ड/मोहल्ला, श्रेणी और टिप्पणी दर्ज करें।
   - **बल्क लिस्ट पेस्ट (Bulk Paste):** WhatsApp, Excel या डायरी से सीधे लिस्ट पेस्ट करें (उदा. `राजेश शर्मा 9829012345` या `सुरेश कुमार, 9829098765`), सिस्टम अपने आप नाम और नंबर अलग कर MongoDB में सेव कर देता है।

2. **1-क्लिक WhatsApp रीडायरेक्ट (WhatsApp Direct Message):**
   - हर मतदाता के आगे दिए गए **"WhatsApp भेजें"** हरे बटन पर क्लिक करते ही सीधे उस व्यक्ति के WhatsApp चैट पर रीडायरेक्ट होता है।
   - संदेश में उस व्यक्ति का नाम स्वतः जुड़ जाता है (उदा. `सादर प्रणाम [नाम] जी...`)।
   - क्लिक होते ही MongoDB में स्थिति **"संपर्क पूर्ण" (Contacted)** में अपडेट हो जाती है।

3. **सीधा कॉल बटन (Direct Call):**
   - मोबाइल या डायलर पर सीधे नंबर डायल करने के लिए कॉल बटन।

4. **कस्टम संदेश टेम्पलेट्स (Customizable Message Templates):**
   - चुनाव सहयोग अपील
   - विकास एवं विजन
   - जनसंवाद बैठक आमंत्रण
   - मतदान दिवस स्मरण
   - अपना मनचाहा कस्टम संदेश लिखने की सुविधा।

5. **सर्च, फ़िल्टर एवं सांख्यिकी (Live Campaign Stats):**
   - कुल मतदाता, संपर्क हो चुके मतदाता और शेष मतदाताओं की लाइव गिनती।
   - वार्ड एवं श्रेणी अनुसार फ़िल्टर।
   - 1-क्लिक CSV/Excel एक्सपोर्ट।

## चालू करने का तरीका (How to Run)

### तरीका 1: सबसे आसान (1-Click)
फ़ोल्डर के अंदर दी गई **`start.bat`** फ़ाइल पर डबल-क्लिक करें। बैकएंड और फ्रंटएंड दोनों एक साथ चालू हो जाएंगे और ब्राउज़र में `http://localhost:5173` खुल जाएगा।

### तरीका 2: टर्मिनल से (Manual)
1. **Backend स्टार्ट करें:**
   ```bash
   cd backend
   node server.js
   ```
   *(चलने लगेगा http://localhost:5000 पर)*

2. **Frontend स्टार्ट करें:**
   ```bash
   cd frontend
   npm run dev
   ```
   *(चलने लगेगा http://localhost:5173 पर)*
